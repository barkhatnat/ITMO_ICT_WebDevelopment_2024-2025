Схема БД

Была создана схема базы данных, состоящая из 5 моделей

Эндпоинты

Auth(/register, /login)

  • POST /register – регистрация нового пользователя
  • POST /login – вход пользователя, возврат JWT access token

User (/users/)

  • POST /users/ – создать нового пользователя
  • GET /users/{user_id} – получить пользователя по ID
  • GET /users/ – получить список пользователей (требуется авторизация)
  • PATCH /users/{user_id} – обновить пользователя по ID
  • DELETE /users/{user_id} – удалить пользователя по ID
  • GET /me – получить текущего авторизованного пользователя
  • POST /users/change-password – сменить пароль текущего пользователя

Book (/books/)

  • POST /books/ – создать новую книгу
  • GET /books/{book_id} – получить книгу по ID
  • GET /books/ – получить список книг
  • PATCH /books/{book_id} – обновить книгу по ID
  • DELETE /books/{book_id} – удалить книгу по ID

Exchange (/exchanges/)

  • POST /exchanges/ – создать обмен
  • GET /exchanges/{exchange_id} – получить обмен по ID (с joinedload связей)
  • GET /exchanges/ – получить список обменов
  • PATCH /exchanges/{exchange_id} – обновить обмен по ID
  • DELETE /exchanges/{exchange_id} – удалить обмен по ID

Review (/reviews/)

  • POST /reviews/ – создать отзыв
  • GET /reviews/{review_id} – получить отзыв по ID
  • GET /reviews/ – получить список отзывов
  • PATCH /reviews/{review_id} – обновить отзыв по ID
  • DELETE /reviews/{review_id} – удалить отзыв по ID

Location (/locations/)

  • POST /locations/ – создать локацию
  • GET /locations/{location_id} – получить локацию по ID
  • GET /locations/ – получить список локаций
  • PATCH /locations/{location_id} – обновить локацию по ID
  • DELETE /locations/{location_id} – удалить локацию по ID

Код подключения к БД

URL для подключения хранится в .env

import os  

from dotenv import load_dotenv  
from sqlmodel import SQLModel, Session, create_engine  

load_dotenv()  
db_url = os.getenv("DB_ADMIN")  

engine = create_engine(db_url, echo=True)  


def init_db():  
    SQLModel.metadata.create_all(engine)  


def get_session():  
    with Session(engine) as session:  
        yield session
